# SillyDroid 熄屏流式暂存（测试版）

## 作用与边界

启用后，小说自动生成器启动的 OpenAI、OpenAI 兼容 custom 和 Vertex AI 流式请求，先由酒馆服务器接收并暂存在内存。页面只是暂停时，回来后从上次读取的位置继续拿取；同一请求 ID 重试不会重复派发。此功能只在本插件任务运行期间接管对应生成请求。页面被冻结时，当前请求可以由服务端继续接收，但网页中的角色队列不会自动推进到下一项，直到页面恢复执行。

必须同时满足：酒馆服务器进程仍在运行、服务器到模型的连接仍可用、页面恢复后原任务仍存在。当前组件按 SillyDroid 默认本机 HTTP 服务设计，暂不支持酒馆服务自身启用 HTTPS 或关闭 IPv4 回环。本功能无法在进程被系统终止后恢复内存，也不支持在页面刷新或 WebView 被销毁重建后自动接续原流。断流后无法取回服务商未送达酒馆的内容，断开期间可能仍产生模型费用。流正常结束但没有可识别的结束标记、或模型报告达到输出上限时，结果会按不完整处理；不遵循常见结束标记的兼容服务也可能被误判。

服务端缓冲默认最多单请求 16 MiB、总计 64 MiB，最多等待 15 分钟；连续 3 分钟没有上游数据则标为超时。服务或应用重启后，内存缓冲会丢失。结果读取完毕后尝试立即释放；未确认的数据最多保留 15 分钟。缓冲只保存在服务器内存，不主动另存正文或凭据。停止任务会尝试通知服务端中止上游请求；网络不可达时，中止通知可能无法送达。

## SillyDroid 安装

以下目录和设置名称依据 SillyDroid 源码 725b593 的实现，其他版本以实际界面为准。操作前保存角色卡和聊天的备份。

1. 在酒馆扩展管理器中更新「小说自动生成器」到 1.10.1 并刷新页面；也可以将下载的完整源码放入现有扩展目录。更新 UI 扩展不会自动安装服务端组件。
2. 将更新后的 UI 扩展目录中的 `server-plugins/novel-stream-buffer` 整个目录复制到酒馆服务器的 `plugins/` 下，形成 `plugins/novel-stream-buffer/index.mjs`。新版 SillyDroid 的 Android 文件选择器暴露「酒馆数据 → 酒馆根目录」，其中服务器插件目录为 `plugins`。
3. 在 SillyDroid 的酒馆设置中打开「启用服务端插件」（`enableServerPlugins`），重启酒馆服务；可按需关闭「自动更新服务端插件」。此前未启用的其他服务器插件也可能随之加载，请先查看该目录。
4. 打开插件控制区，勾选「任务流式回复由服务端暂存」，并开启酒馆的流式输出。开始任务时插件会检查服务器组件；未安装或未启用时会提示并拒绝本次启动，不会默默按未保护模式运行。
5. 先用新建测试聊天、小批次和合成或短回复验证开始、熄屏、亮屏、结果完整、停止和刷新，再用于重要聊天。小米设备实际后台策略与 WebView 版本仍需实机验证。

要撤回：关闭「任务流式回复由服务端暂存」，停止酒馆后移除 `plugins/novel-stream-buffer`。不再需要其他服务器插件时，可在设置中关闭「启用服务端插件」并重启。关闭该总开关会同时关闭其他服务器插件。

## 已测试和未测试

隔离 SillyTavern 1.18.0 + 桌面 Chromium 的真实酒馆生成流程中，对 OpenAI 兼容格式及 Vertex AI 格式分别使用本机合成服务：第 2 片段时通过 CDP 冻结页面，模拟服务发完 20 片段后恢复页面，结果 20/20 且只派发一次；测试了人工停止、重复 start、旧服务版本标识、先取消后启动和服务端缓冲释放。模拟上游断流时，将测试副本的空闲超时缩短到 3 秒，酒馆保留部分正文并标记 partial/failed，而非 complete；实际构建的空闲超时仍为 3 分钟。

没有实际调用 Google Vertex AI 或真实 OpenAI 服务；没有小米 HyperOS 设备、SillyDroid APK 与系统 WebView 实机测试。CDP 页面冻结不等于手机熄屏、Doze、断网、重建 WebView 或杀进程。正式使用前必须在目标设备和服务商上实测。
