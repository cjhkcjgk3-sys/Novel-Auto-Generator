## 本仓库专属

- **检查命令**：提交前跑 `npm run verify`（含 Prettier 格式检查），已有的失败要说明，不能新增失败。
- **版本与更新记录**：用户可见的改动要升版本号（`manifest.json` 与 `package.json` 一致），并在 `CHANGELOG.md` 写明改动和“更新人”。
- **界面类名**：新界面照着插件已有元素用：按钮 `menu_button`，设置行 `nag-setting-item`，勾选框 `nag-checkbox-label`（绿色 `#8bc34a`），状态标签 `nag-status-badge`，弹窗 `nag-modal`／`nag-modal-header`／`nag-modal-close`，折叠区 `nag-collapsible`，名单行 `nag-role-status-row`。
- **名字匹配**：作品名可选 + 角色名 + 备注；只忽略全／半角、括号、标点和空格。写了备注但没有对应形态图时按无图处理，不拿本体图顶替；不做包含或模糊匹配（`小安比` 不配 `安比`）；有多张候选时不用图。
- **图片库**：图片仓库 ZIP 按需读取，不整包读进内存；图片仓库的 `tools/check.py` 要和这里的匹配规则一致。
- 问题记录见 [问题与解决记录](问题与解决记录.md)。
